# Generador de Cliente Ideal + Contenido

Mini app estática de Método a Mil. No requiere instalar dependencias ni configurar claves.

## Abrir localmente

Abre `dist/index.html` en tu navegador o ejecuta un servidor estático dentro de `dist`.

## Publicar en Vercel

1. Sube esta carpeta a un repositorio de GitHub.
2. En Vercel, elige **Add New → Project** e importa el repositorio.
3. Deja **Framework Preset** en `Other`.
4. Configura **Output Directory** como `dist` si Vercel no lo detecta automáticamente.
5. Pulsa **Deploy**.

La aplicación funciona completamente en el navegador y no envía las respuestas a ningún servidor.
